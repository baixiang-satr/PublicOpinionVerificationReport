## 1. 软件简介

舆情验证报告工具是一个运行在 Windows 上的本地桌面软件。你给它一批网页链接（URL），它会：

1. 用真实浏览器逐个打开网页，识别网页属于哪个平台（抖音、小红书、知乎……共 34 个）；
2. 自动提取标题、正文、作者账号、昵称、发布时间等字段；
3. 为每条记录保存**内容页截图**，并在能进入作者主页时保存**作者主页截图**；
4. 把结果按平台自动分进固定交付模板的 **8 张工作表**，打包生成 **`template.zip`** 交付包。

抓取不到的字段和记录不会凭空编造，而是标记为「待补录」，由你在内置表格中对照原页面人工补齐、
人工框选补截图，最终导出与模板完全一致（工作表、表头、下拉选项、格式、保护均不变）的交付包。

**界面总体布局**：软件采用「一页一件事」的向导式布局——

- 左侧是**步骤条**，共 6 步：欢迎 → 输入与参数 → 抓取执行 → 抓取结果 → 采集与补录 → 预览导出；
- 每页顶部有一条**提示条**，告诉你当前这一步该做什么；
- 右下角是「上一步 / 下一步」导航按钮；第 1 步点「开始抓取 →」会自动进入抓取；
- 窄窗口下左侧步骤条会自动折叠为顶部横向步骤条。

## 2. 运行环境与启动

### 2.1 免安装包（推荐）

交付给你的通常是一个压缩包，解压后得到「舆情验证报告工具」文件夹：

1. **整个文件夹**解压到任意位置（不要只解压出 exe，全部文件都要保留）；
2. 双击「舆情验证报告工具.exe」即可运行——不需要安装 Python、Node.js 或任何浏览器；
3. 首次启动较慢（约 5~15 秒）属正常现象；若杀毒软件提示，请选择允许运行。

环境要求：

- Windows 10 / 11（64 位）；
- 系统自带 WebView2 运行时（Win10/Win11 一般已有；若启动后窗口空白，请从微软官网搜索
  “WebView2 Runtime” 安装后重试）；
- 不需要联网激活授权（授权为离线校验），但抓取网页本身需要网络。

文件夹内重要组成：**请勿删除或改名**——`template/`（固定交付模板）、`ms-playwright/`（随包浏览器）、
`poir_ocr_worker.exe`（独立 OCR 识别组件）、`web/`（界面资源）。每次任务的输出会自动写入
exe 同级的 `output/` 目录。

### 2.2 源码运行（开发 / 维护人员）

```powershell
pip install -r requirements.txt
python -m playwright install chromium
python -m src.main
```

要求 Windows 10/11、Python 3.11+。详见 [developer_guide.md](developer_guide.md)。

## 3. 授权码操作指南

本工具采用**离线一机一码授权**：每个授权码绑定一台电脑、一个到期时间，由供应商用私钥签发，
软件内置公钥验签，**激活和日常使用全程无需联网验证**。未激活时，软件只显示激活页，
其余功能（选文件、抓取、截图、导出等）一律不可用。

### 3.1 首次激活（四步）

1. **启动软件**，未激活时自动进入「软件授权激活」页；
2. 页面上方显示**本机机器码**（形如 `XXXX-XXXX-XXXX-XXXX-XXXX-XXXX` 的 24 位编码），
   点击「**复制机器码**」，通过微信、邮件等方式发送给供应商；
3. 供应商返回一串以 **`POIR1.` 开头的授权码**后，把它完整粘贴到「授权码」输入框；
4. 点击「**激活**」，提示授权成功即自动进入正常界面。

之后每次启动软件都会自动校验本机已保存的授权，**无需重复激活**。

### 3.2 授权状态与提示含义

激活页和操作拦截提示中可能出现的全部状态如下：

| 界面提示 | 含义 | 处理办法 |
| --- | --- | --- |
| 尚未激活，请输入授权码完成激活。 | 本机从未激活，或授权文件被删除 | 按 3.1 流程激活 |
| 授权码格式无效，请核对后重新输入。 | 粘贴的内容不是完整授权码 | 检查是否漏复制、混入多余文字，重新完整粘贴 |
| 授权码校验失败，请确认授权码完整无误。 | 授权码被篡改或已损坏 | 向供应商重新索取授权码 |
| 该授权码与本机不匹配，一机一码无法跨机使用。 | 授权码绑定的是另一台电脑 | 复制本机机器码给供应商，换领本机专用授权码 |
| 授权已于 XXXX-XX-XX 到期，请联系供应商续期。 | 授权已过有效期 | 联系供应商续期（见 3.4） |
| 无法读取本机标识，请确认在受支持的 Windows 环境运行。 | 软件读不到本机机器码 | 确认在受支持的 Windows 10/11 上以正常方式运行 |
| 已授权给 ×××，有效期至 XXXX-XX-XX。 | 授权有效 | 正常使用 |

### 3.3 日常使用中的授权拦截

激活后无需再操心授权，但请注意两点：

- **启动校验**：每次启动软件自动校验，授权有效则直接进入欢迎页；
- **操作拦截**：即使软件已在运行，只要授权变为无效（例如到期），选择 URL 文件、开始抓取、
  框选截图、平台登录、导出等关键操作都会被拦截，界面自动切回激活页，按提示处理即可恢复。

### 3.4 到期续期

授权到期后软件回到激活页。续期流程与首次激活相同：

1. 在激活页点击「复制机器码」发给供应商，并说明是**续期**；
2. 收到新授权码后粘贴、点击「激活」即可，已采集的任务数据不受影响。

建议提前留意激活时提示的到期日，在到期前联系供应商办理续期，避免影响使用。

### 3.5 换机、重装系统与注销

- **授权码与机器码绑定**，把授权码复制到其他电脑无法使用；
- **重装 Windows、更换主板后机器码会变化**，视同换机：在新环境下重新打开软件，
  复制新的机器码给供应商，换领新授权码；
- 授权信息保存在当前 Windows 用户的
  `%LOCALAPPDATA%\PublicOpinionVerificationReport\license.dat`（系统级加密存储）。
  删除该文件即回到未激活状态，需要重新输入授权码激活；
- 换 Windows 用户登录同一台电脑，也需重新激活（授权文件按用户保存）。

### 3.6 授权安全说明（如实告知）

- 授权码由供应商离线签发，软件只验签不联网，激活记录不会上传；
- 机器码是根据电脑硬件/系统标识加盐计算出的短码，不包含你的任何个人信息；
- 本机制防止“一个授权码随意复制给多台电脑使用”。请妥善保管授权码，勿外发无关人员。

> 供应商签发授权码的操作（生成密钥、签发、查验）见 [license_guide.md](license_guide.md)，
> 该工具不随安装包分发。

## 4. 平台功能详解

本章按操作顺序详细介绍软件的全部功能。整体流程为六步向导：

```text
欢迎 → 输入与参数 → 抓取执行 → 抓取结果 → 采集与补录 → 预览导出
```

### 4.1 第 0 步 · 欢迎：两种开始方式

软件激活后进入欢迎页，提供两种开始方式：

| 方式 | 适用场景 | 说明 |
| --- | --- | --- |
| **新建采集任务** | 第一次采集一批 URL | 准备一个包含网页链接的 TXT、CSV 或 XLSX 文件，从第 1 步开始完整流程 |
| **上传 template.zip 补录** | 之前生成过交付包，还想继续改 | 选择之前生成的 `template.zip`，软件把它还原成新任务目录（`output/<时间戳>-imported-xxx/`），已填写的 8 张表内容、已关联的截图全部恢复，直接进入「采集与补录」继续修改、补空缺、换截图，然后导出新包 |

### 4.2 第 1 步 · 输入与参数

#### 4.2.1 选择 URL 文件

- 点击「**选择文件…**」选择 TXT、CSV 或普通 `.xlsx` 文件；
- 文件中只要出现 `http://` 或 `https://` 链接就会被自动识别提取，
  无关文字自动忽略；**重复链接只处理一次**，按首次出现的顺序编号；
- 选择后界面显示“已识别 N 条有效 URL”，无效条目数也会提示；
- **注意**：不要把软件目录里的 `template/template.xlsx` 当作输入文件，
  它是固定交付基准，软件会自动复制并填写副本，源模板永不被修改。

#### 4.2.2 运行参数（不懂就保持默认）

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| 同时处理 | 1~10 | 并行抓取的页面数。数值越大越快，但增加电脑负担和反爬风险，**建议 3~5** |
| 单页超时 | 5~180 秒 | 超过该时间仍未加载完成的页面按超时处理 |
| 失败重试 | 0~5 次 | 抓取失败后的自动重试次数，0 表示出错就跳过 |
| 截图格式 | JPG / PNG | JPG 体积更小；PNG 文字更清晰 |
| 浏览器模式 | 固定 | 后台有界面浏览器：保留真实浏览器指纹与登录态，窗口在后台运行、任务结束后自动退出，不抢占前台；只有登录和人工截图时才显示窗口 |

#### 4.2.3 管理平台登录态（首次使用必做）

点击「**管理平台登录态…**」打开登录态管理中心。绝大多数平台必须登录后才能看到完整内容，
软件**只抓取已保存有效登录态的平台**，没有有效登录态的平台不会开始访问。

登录态管理中心要点：

- 平台分两组显示：「**本次 URL 涉及的平台**」在上，「其他平台（本次未涉及）」在下；
  每个平台一张卡片，显示状态点、平台名称、登录状态、已保存账号（脱敏）和说明；
- **打开窗口时会自动复验本次涉及的平台**，登录态过期会立即显示，不用等到抓取时才发现；
  验证过程中如果长时间无响应，可点「取消」中止后重试（后台也有超时兜底，不会一直转圈）；
- **登录流程**：逐个点「**登录 / 更新**」→ 软件打开该平台**唯一一个官方登录界面**（稳定显示，
  不会自动关闭）→ 你在页面里自行完成密码、短信验证码或扫码登录 → 回到登录态中心点
  「**完成登录并保存**」。软件确认凭据后按平台加密保存并关闭登录窗口；
- 一次只处理一个平台，避免多个登录窗口来回切换；
- 「**验证**」按钮可随时单独复验某个平台：保存的 Cookie 仍有效时会自动恢复为
  “登录态有效”，无需重新登录；
- 「**退出登录**」删除本机保存的该平台登录态（有二次确认）；
- 开始抓取前，请确保“本次 URL 涉及的平台”**全部显示“登录态有效”**。

登录态安全说明：登录态按平台独立保存，由 Windows DPAPI 绑定当前系统用户加密，
**不会进入交付包**；索引只保留脱敏手机号和验证结果，不保存明文 Cookie/Token。
短信验证码、密码和扫码只在平台官方页面中处理，软件不会自动发送验证码、不会破解验证码。

#### 4.2.4 抓取中登录失效的处理

抓取过程中如果某平台登录态实际已失效，软件会自动弹出该平台登录窗口（**一次只弹一个，
完成后再弹下一个**），并显示「需要重新登录」对话框，你有三种选择：

| 选择 | 效果 |
| --- | --- |
| 完成登录并保存 | 在弹出的平台页面完成登录后点此项，保存登录态并从中断处继续抓取 |
| 重试登录 | 登录失败或窗口异常时重新发起登录流程 |
| 跳过该平台 | 该平台剩余 URL 本次不再抓取，转入待补录清单，其他平台不受影响 |

单条 URL 遇到登录墙只影响该条记录：已保存的登录态不会被误判过期、不会被删除。
同平台采用串行健康门禁——首条记录确认登录失效后，该平台剩余记录暂停访问并保留表格位置，
待登录态恢复后可通过「重试失败项」继续。

### 4.3 第 2 步 · 抓取执行

从第 1 步点「开始抓取 →」会自动进入本步并开始抓取；也可以在本页手动点「**开始抓取**」。

界面内容：

- **进度条**：整体完成百分比与当前阶段（准备中 / 抓取中 / 导出中……）；
- **统计卡片**：共 N 条、已完成、成功、待补录、失败的实时数量；
- **正在处理**：当前正在抓取的 URL；
- **取消任务**：随时可取消。软件会等待当前浏览器操作安全结束并关闭资源；
  已完成记录仍可查看，但**取消不会生成不完整的压缩包**。

「**高级操作**」折叠区提供三个恢复类功能：

| 按钮 | 用途 |
| --- | --- |
| 重试失败项 | 保留已成功记录，只重新抓取失败和待补录的 URL（修复登录态、网络后使用） |
| 从断点继续 | 任务中断（如意外关闭）后，从上次断点接着抓取 |
| 仅重新导出 | 不启动浏览器，直接用断点记录重新生成 template.zip |

「**运行日志**」折叠区可实时查看每条 URL 的处理过程、状态码和错误原因。

抓取策略说明（了解即可）：

- 所有网站一律使用可见浏览器内核抓取，**不做游客模式降级**；
- 页面字段按优先级提取：平台专用规则 → JSON-LD / 内嵌状态 → 内容型网络载荷 → Meta →
  可见文本；只读取页面本次正常加载得到的数据，不绕过访问权限；
- 登录墙、验证码页、空白页、跳回首页、内容失效页会被自动识别，**不会当作成功证据截图**；
- 纯图片型页面（正文无文字）会自动启用 **OCR 图片文字识别**提取图中文字作为正文，
  识别结果以“以下为图片中识别文字，内容为：”前缀标记；识别用临时图片用完即删，不进交付包。

### 4.4 第 3 步 · 抓取结果

抓取完成后自动进入本步，结果已按交付模板的 **8 张工作表**排好，列名与最终交付表完全一致。

- 顶部汇总：总记录 / 已完整 / 待补录数量；
- 各工作表标签显示 `表名 已完成/总数`，绿色=全部完整，橙色=有待补录，灰色=无记录；
- 点「**预览表格**」弹出只读表格窗口：
  - 与最终交付表完全一致的列名、顺序和下拉；
  - 表格最后多出的「**状态 / 待补字段**」两列只是给你看的，**不会写进交付包**；
  - 长文字一律裁剪在单元格内不遮盖相邻列：点击任意单元格，上方「**单元格内容**」栏显示
    完整内容；鼠标悬停片刻也会弹出限长提示；
  - URL 等蓝色链接单元格点击即可在系统浏览器中打开原页面。

记录状态常见含义：`已就绪`（内容与截图齐备）、`待补录`（有必填项缺失，如
`PARTIAL_FIELDS_MISSING` 部分字段未能可靠获取）、`失败`（页面打不开、已删除、被风控等，
错误原因可在日志查看）。待补录和失败的记录可在第 4 步人工补齐。

### 4.5 第 4 步 · 采集与补录

点「**打开补录表格**」弹出可编辑表格窗口（操作方式与 WPS/Excel 表格一致）：

#### 4.5.1 编辑与保存

- 表格与交付模板一模一样，**下拉选项完全相同**（发布平台、文本类型、处置对象等）；
- **红色空格是必补项**，补齐后红色消失；
- **修改即自动保存**（按任务保存在本机 `manual_overrides.json`），无需手动保存；
- URL 单元格点击即可打开原页面，方便对照取证。

#### 4.5.2 手工行（群聊 / 朋友圈 / 无 URL 内容）

群聊、朋友圈工作表没有 URL 列，无法通过网址抓取，用「**添加手工行**」补录：

1. 在工具条的下拉框选择目标工作表（如“群聊”“朋友圈”）；
2. 点「**添加手工行**」，表格新增一行空白记录（自动分配证据编号）；
3. 直接在单元格中填写内容；点截图按钮时会改为**从本地选择图片**（如手机转存的聊天截图）；
4. 选错的手工行可用「**删除手工行**」移除（只有无 URL 的手工行能删除，抓取记录不可删）。

#### 4.5.3 人工框选截图（补截图 / 换截图）

每条记录有两张截图：**内容页截图**和**个人页（作者主页）截图**。操作步骤：

1. 在表格中**选中目标记录行**；
2. 点「**截取内容页**」或「**截取个人页**」：软件最大化打开目标页面
   （自动带上已保存的平台登录态；截个人页时可先在页面里点进作者主页）；
3. 在窗口右上角工具条点「**开始框选**」：整个屏幕（**含浏览器地址栏 URL**）冻结成图；
4. 用鼠标拖拽框选任意屏幕区域，松开即保存；
5. 截图自动规范命名（如 `001_content.jpg`、`001_author.jpg`）并关联到该记录，
   重新截取会覆盖旧图。

「**查看截图**」可预览已保存的截图：两张齐全时并排显示；缺一张会提示你补哪张；
一张都没有会提示先去截图。多显示器环境下框选同样可用。

### 4.6 第 5 步 · 预览与导出

- 顶部提示条显示**导出前检查清单**：共 N 条记录、M 条已完整、各工作表完成情况；
  仍待补录的记录会按空缺导出（对应单元格留空），建议先回第 4 步补齐；
- 「**预览表格**」：最终 `template.xlsx` 的样子（含全部人工补录），只读确认；
- 「**导出 template.zip**」：生成固定格式交付包。导出前软件自动校验模板完整性、
  附件与表格引用一一对应，**没有任何可安全导出的记录时不会生成空包**；
- 导出成功后弹窗显示文件位置，点「**打开输出位置**」直接打开所在文件夹。

关于导出文件的说明：

| 文件 | 说明 |
| --- | --- |
| `template.zip` | 抓取完成后生成的初版交付包（位于 `output/<任务编号>/`） |
| `template_final.zip` | 在「采集与补录」做过人工修改后再导出时，同目录额外生成的补录最终版，以它为准 |

### 4.7 任务中断保护

- 任务进度、截图和人工补录内容会实时镜像保存到本机恢复区
  （`%LOCALAPPDATA%\PublicOpinionVerificationReport\recovery\`）。软件异常关闭后，
  重新打开任务可通过「从断点继续」「仅重新导出」恢复，截图不会丢；
- 软件万一崩溃，会自动写入崩溃日志（`%LOCALAPPDATA%\PublicOpinionVerificationReport\logs\crash-*.log`），
  请把它提供给维护人员定位问题。

## 6. 输出物与本机审计文件

### 6.1 交付包 template.zip

解压后是一个 `template/` 顶层目录，包含固定文件名的 `template.xlsx`、各记录的内容页截图
（如 `001.jpg`）和作者主页截图（如 `001主页.jpg`）。Excel 中每一个截图/附件文件名都能在
ZIP 内找到同名实际文件；包内不含任何日志、Cookie、调试数据。

### 6.2 本机任务目录（不交付）

每次任务位于 `output/<任务编号>/`，除 `template.zip` 外还有以下**仅供你本机核查**的文件，
它们不会进入交付包：

| 文件 / 目录 | 用途 |
| --- | --- |
| `staging/` | 任务副本和排错材料 |
| `quality_report.md` | 按平台统计成功率、字段覆盖率、截图数量和错误码 |
| `quality_summary.json` | 供自动比较不同批次质量 |
| `pending_manual_entry.csv` | 失败或字段不完整的证据编号、原始 URL、错误原因和建议操作，可直接用 Excel 打开 |
| `manual_overrides.json` | 你在「采集与补录」中人工修改/填写的内容，按任务保存 |
| `manual_assets/` | 人工框选/上传的截图，导出时自动复制进交付包 |

标题、作者主页 URL、HTTP 状态码、重定向信息和错误原因会显示在软件界面与本机日志中；
由于固定模板没有对应列，它们不会写入 ZIP。

## 7. 使用限制与合规边界

- 本工具只处理你有权处理的公开信息；**不自动破解验证码，不绕过付费墙、登录权限或
  站点访问控制**。需要登录的平台一律由你本人在官方页面完成登录；
- 平台首页、搜索页和猜测的文章 ID 不属于有效内容证据，请输入从平台正常浏览流程取得的
  真实内容 URL；
- “URL 失效/页面为空”通常应更换真实内容 URL；解析、字段映射和导出错误属于软件问题，
  请联系维护人员，重复登录通常无效；
- 受保护页面（登录墙、验证码等）不会被当作证据截图；微信视频号必须完成二维码登录并保存
  登录态，不能只停留在公开分享页；
- 登录态、授权信息均保存在本机并按当前 Windows 用户加密，换电脑或换系统用户后需要
  重新登录平台、必要时重新激活授权；
- 源 `template/` 从不被软件覆盖。若发现源模板被手动修改，请停止使用并联系维护人员
  重新确认模板。

## 8. 常见问题（FAQ）

**Q1：双击 exe 没反应？**
等 15 秒（首次启动较慢）；仍无反应请检查杀毒软件拦截记录，将本软件加入信任后重试。

**Q2：启动后窗口空白？**
系统缺少 WebView2 运行时，从微软官网搜索 “WebView2 Runtime” 安装后重试。

**Q3：粘贴授权码提示“与本机不匹配”？**
授权码绑定的是另一台电脑。在激活页复制**本机**机器码发给供应商换领。

**Q4：提示授权已到期怎么办？**
联系供应商续期，拿到新授权码后在激活页粘贴激活即可，数据不受影响。

**Q5：重装系统后授权没了？**
重装 Windows 或更换主板后机器码会变化，视同换机，需要重新获取授权码。

**Q6：抓取一直显示某平台“需要重新登录”？**
说明保存的登录态已失效。打开「管理平台登录态…」先点「验证」——Cookie 仍有效会自动恢复；
确实失效再点「登录 / 更新」重新登录并保存。

**Q7：某条记录一直是“待补录”？**
先检查该平台登录态是否有效，再用「重试失败项」；若原网页已删除、被风控或必须在手机 App
内打开，则对照原页面证据在第 4 步人工补录。

**Q8：截图窗口打不开？**
确认没有同时开着其他截图窗口，关闭后重试。

**Q9：提示“没有可安全导出的记录”？**
查看抓取结果中的错误列；补充合法登录态、恢复网络或修正输入文件后再重试。

**Q10：提示“模板完整性检查失败”？**
不要编辑软件目录下的 `template/template.xlsx`，恢复原始模板后重新运行。

**Q11：可以同时在多台电脑使用吗？**
授权码一机一码，每台电脑需要各自的授权码；登录态也按机器和用户独立保存。
