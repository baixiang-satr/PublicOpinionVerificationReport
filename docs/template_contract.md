# 固定模板交付契约

本清单是 [requirements.md](../requirements.md) 中模板要求的开发速查版。发生冲突时以需求文档和实际 `template/` 目录为准。

## 不可变项

- 源目录 `template/`：只读，不得改名、清空、写入或重打包。
- 工作簿文件名：`template.xlsx`。
- 工作表名称和顺序：电商平台、公众号、群聊、朋友圈、图文视频、微博博客、生活资讯、浏览器。
- 工作表的第 1 行字段名、第 2 行示例/提示、数据验证、日期格式、保护、行高和列宽。
- 最终压缩包名称：`template.zip`。

## 允许写入项

- 仅写入 staging 副本中第 3 行之后的可填写业务单元格。
- 清除副本已有业务值时只能清除值，不能删除行列或破坏验证/格式。
- 页面主截图写入各表指定的截图列；作者主页截图写入“其他附件/其他文件名”列。正文图片不进入交付包。
- 日期写入 Excel 原生日期时间；附件只写安全文件名，用英文逗号分隔。

## 导出前检查

1. 源 `template/` 的递归哈希清单与任务开始时一致。
2. 每行必须有主截图并符合下拉枚举；页面已取得标题或正文时，其他无法公开取得的字段允许保持空白。
3. 每个截图/附件文件名都不含路径且在 staging `template/` 根目录存在。
4. staging 内没有未被 Excel 引用的本次资产、日志、浏览器缓存或 JSON 文件。
5. Excel 重新打开后仍有 8 张表、原顺序、首行、数据验证和保护，且没有修复提示。
6. ZIP 中每一个文件都位于 `template/` 顶层目录下。

## 禁止项

- 使用 `openpyxl`、pandas、xlsxwriter、SheetJS 等重建/另存固定模板。
- 增加状态码、错误信息、标题或作者主页 URL 列。
- 将运行日志、Cookie、浏览器 profile、调试 HTML 或临时 JSON 放进 ZIP。
- 以 Excel 行号代替全局证据编号，或写入不存在的附件名称。
