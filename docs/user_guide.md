# 用户使用指南

## 系统要求

- Windows 10/11
- Python 3.11 及以上
- Microsoft Excel（仅当模板为旧式 OLE 格式且需要 Excel COM 回退时）
- Playwright Chromium 浏览器

首次安装并启动：

```powershell
pip install -r requirements.txt
python -m playwright install chromium
python -m src.main
```

## 准备输入

工具支持 TXT、CSV 和普通 `.xlsx` URL 清单。URL 必须为 `http://` 或 `https://` 链接；重复链接只会处理一次，并按首次出现顺序编号。

请不要把项目中的 `template/template.xlsx` 当作输入文件或直接编辑。它是固定的交付基准，任务会自动复制并填写副本。

## 操作流程

1. 在“第 1 步”选择或拖入 URL 文件。
2. 在“第 2 步”检查并发数、超时、重试次数和截图格式；不确定时保持默认。
3. 首次使用时点击“管理平台登录态…”，再点“验证全部（游客优先）”。“游客可访问”的平台不需要登录。
4. 对状态为“需要登录”或“需要人工验证”的平台，选中后点击“登录 / 更新选中”。可选填手机号；工具只辅助填入可识别的手机号输入框，不会点击发送验证码。
5. 在打开的平台官方页面中自行输入验证码、密码或完成扫码。页面恢复后，工具会用全新的浏览器 context 复验；显示“登录态有效”即保存。若探测页临时失效（商品下架、页面为空），人工登录的成果也会直接保存，不会被丢弃。
6. 点击“开始生成”，在任务进度、抓取结果和运行日志中查看实时状态。抓取会按 URL 自动选择对应平台的独立登录态。
7. 任务完成后点击“打开输出位置”取得 `template.zip`，并查看同目录下的质量报告和待补录清单。
8. 有失败或待补录记录时，可点击“重试失败项”。新任务会保留上一轮已导出的成功记录，只重新抓取失败项并合并生成新包。
9. “从断点继续”复用最近一次任务的断点记录，只抓取尚未完成的 URL；“仅重新导出”不启动浏览器，直接用断点记录重新生成 `template.zip`。两者都需要先选择与原任务相同的 URL 文件。

运行中点击“取消任务”后，程序会等待当前浏览器操作安全结束并关闭资源；已完成记录仍可查看，但不会生成不完整压缩包。

## 输出说明

`template.zip` 解压后有一个 `template/` 顶层目录，包含固定文件名 `template.xlsx`、页面截图和可取得时的作者主页截图。每条记录最多两张截图，所有文件与 Excel 中的截图/附件名称一一对应。默认使用 `OoxmlTemplateWriter` 直接写入 Office Open XML，无需桌面 Excel。

每次任务位于 `output/<任务编号>/`。其中 `staging/` 是任务副本和排错材料，固定格式交付物是同目录下的 `template.zip`。ZIP 外还会生成：

- `quality_report.md`：按平台统计成功率、字段覆盖率、截图数量和错误码。
- `quality_summary.json`：供后续自动比较不同批次质量。
- `pending_manual_entry.csv`：列出失败或字段不完整的证据编号、原始 URL、错误原因和建议操作，可直接用 Excel 打开。

这些审计文件不会进入 `template.zip`。

标题、作者主页 URL、HTTP 状态码、重定向信息和错误原因会显示在本机任务结果与日志中；由于固定模板没有相应列，它们不会被额外写入 ZIP。

## 常见限制

- 群聊与朋友圈工作表没有 URL 列，当前网页 URL 批处理不会自动填充它们。
- 未在模板枚举中的平台不会被猜测归类，会显示为“未匹配模板平台”。
- 登录墙、验证码、JavaScript 空壳、无法识别的 JSON/API 响应、跳回首页、内容失效和空白页会在截图前被识别。登录态管理器允许人工处理登录/验证码，工具不会自动破解或绕过访问控制。
- 抓取中某一条 URL 遇到登录墙只影响该条记录：保存的登录态不会被判定过期，也不会被删除。只有登录态管理器里的复验明确看到登录墙，平台状态才会变为“登录态已过期”。
- 状态为“登录态已过期”时，加密登录态文件仍保留在本机。先在登录态管理中点击“验证选中”：若保存的 Cookie 仍有效会自动恢复为“登录态有效”，无需重新登录；确实失效时再人工登录。抓取任务遇到“已过期”平台也会先自动复验一次，通过则照常抓取。
- 同平台使用串行健康门禁；首条记录确认登录失效或需要人工验证后，剩余记录暂停访问并保留表格位置，待登录态复验后可通过“重试失败项”继续。
- 页面会优先读取 JSON-LD、Next/Nuxt hydration 和内容型 XHR/Fetch JSON，再回退到 Meta、DOM 和可见文本；只读取页面本次正常加载得到的数据，不绕过访问权限。
- 登录态按平台独立保存，默认由 Windows DPAPI 绑定当前系统用户加密，不进入 `template.zip`。索引只保留脱敏手机号和验证结果；状态损坏时抓取会安全回退，不会自动删除原文件。登录态文件只会在你点击“删除选中登录态”时被移除。
- “URL 失效/页面为空”通常应更换真实内容 URL；解析、字段映射和 Excel 导出错误需要修代码，重复登录通常无效。
- “旧版综合登录态（兼容）”仅用于导入以前的 Playwright JSON；经平台域名过滤和新 context 复验后，才会迁移为单平台加密状态。
- 平台首页、搜索页和猜测的文章 ID 不属于有效内容证据；请输入从平台正常浏览流程取得的真实内容 URL。
- 作者主页要求登录或访问验证时只记录警告，不生成误导性的主页截图，也不阻断已满足模板要求的主页面记录。
- 页面图片只在 HTML 正文为空时作为临时 OCR 输入，识别结束即删除，不进入附件列或 ZIP。
- 只要取得标题或正文且主截图成功，记录就会按已取得内容写入 Excel；无法可靠获取的账号、店铺名、发布时间等字段保持空白，并在界面中显示 `PARTIAL_FIELDS_MISSING` 提醒。
- 源 `template/` 从不被覆盖。若发现源模板被手动修改，请停止任务并联系维护人员重新确认模板契约。

## 常见提示

- “无法启动 Chromium”：执行 `python -m playwright install chromium` 后重试。
- “无法调用 Microsoft Excel”：确认 Windows 已安装桌面版 Excel，且 pywin32 已通过依赖文件安装。默认使用 `OoxmlTemplateWriter` 无需 Excel COM。
- “没有可安全导出的记录”：查看抓取结果中的错误列；补充合法登录态、恢复网络或修正输入后再重试。
- “模板完整性检查失败”：不要编辑 `template/template.xlsx`，恢复项目提供的原始模板后重新运行。
