# 用户使用指南

## 系统要求

- Windows 10/11
- Python 3.11 及以上
- Microsoft Excel，且允许本机程序自动化打开和保存工作簿
- Playwright Chromium 浏览器

首次安装并启动：

```powershell
pip install -r requirements.txt
python -m playwright install chromium
python -m src.main
```

## 准备输入

工具支持 TXT、CSV 和普通 `.xlsx` URL 清单。URL 必须为 `http://` 或 `https://` 链接；重复链接只会处理一次，并按首次出现顺序编号。

请不要把项目中的 `template/template.xlsx` 当作输入文件或直接编辑。它是固定的交付基准，任务会自动复制并填写副本。

## 操作流程

1. 在“第 1 步”选择或拖入 URL 文件。
2. 在“第 2 步”检查并发数、超时、重试次数、截图格式和图片限制；不确定时保持默认。
3. 普通公开页面无需登录态。需要合法登录时，可选择自己的 Playwright storage state JSON，或取消“后台运行浏览器”。
4. 点击“开始生成”，在任务进度、抓取结果和运行日志中查看实时状态。
5. 任务完成后点击“打开输出位置”取得 `template.zip`。
6. 有失败或待补录记录时，可点击“重试失败项”。新任务会保留上一轮已导出的成功记录，只重新抓取失败项并合并生成新包。

运行中点击“取消任务”后，程序会等待当前浏览器操作安全结束并关闭资源；已完成记录仍可查看，但不会生成不完整压缩包。

## 输出说明

`template.zip` 解压后有一个 `template/` 顶层目录，包含固定文件名 `template.xlsx`、页面截图、作者主页截图和下载成功的页面图片附件。所有文件与 Excel 中的截图/附件名称一一对应。

每次任务位于 `output/<任务编号>/`。其中 `staging/` 是任务副本和排错材料，正式交付物只有同目录下的 `template.zip`。

标题、作者主页 URL、HTTP 状态码、重定向信息和错误原因会显示在本机任务结果与日志中；由于固定模板没有相应列，它们不会被额外写入 ZIP。

## 常见限制

- 群聊与朋友圈工作表没有 URL 列，当前网页 URL 批处理不会自动填充它们。
- 未在模板枚举中的平台不会被猜测归类，会显示为“未匹配模板平台”。
- 验证码、登录墙、访问控制、频率限制或页面结构变化可能导致抓取失败；工具不会尝试绕过它们。
- 作者主页要求登录或访问验证时只记录警告，不生成误导性的主页截图，也不阻断已满足模板要求的主页面记录。
- 页面图片只有在状态码、MIME、真实文件格式和大小校验通过并成功写盘后，才会出现在附件列。
- 作者账号、公众号微信号、店铺名等模板必填字段无法可靠获取时，记录会进入待人工补录，而不是生成不可信的 Excel 行。
- 源 `template/` 从不被覆盖。若发现源模板被手动修改，请停止任务并联系维护人员重新确认模板契约。

## 常见提示

- “无法启动 Chromium”：执行 `python -m playwright install chromium` 后重试。
- “无法调用 Microsoft Excel”：确认 Windows 已安装桌面版 Excel，且 pywin32 已通过依赖文件安装。
- “没有可安全导出的记录”：查看抓取结果中的错误列；补充合法登录态、恢复网络或修正输入后再重试。
- “模板完整性检查失败”：不要编辑 `template/template.xlsx`，恢复项目提供的原始模板后重新运行。
